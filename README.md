# Backend of AI Feedback MS

A backend part of AI Feedback Management System.

## Tech Stack

- `express` : Fast,  minimalist web framework for Node.js applications.

- `huggingface/inference` : Official client library to interact with Hugging Face Inference API models.

- `bcryptjs` : A library in pure JavaScript for secure password hashing.

- `cookie-parser` : Middleware to parse HTTP request cookies and populate req.cookies.

- `cors` : Express middleware to enable Cross-Origin Resource Sharing with various options.

- `dotenv` : Zero-dependency module that loads environment variables from a .env file.

- `jsonwebtoken`: Implementation of JSON Web Tokens to securely transmit information and authenticate users.

- `mongoose` : MongoDB object modeling tool designed to work in an asynchronous environment.
